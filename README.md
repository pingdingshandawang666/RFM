# RFM 客户价值分析项目

## 📊 项目简介
这是一个基于Python的RFM客户价值分析系统，用于对电商/零售行业的客户进行分层分析。通过分析客户的历史交易数据，从**最近一次消费(Recency)、消费频率(Frequency)、消费金额(Monetary)**三个维度对客户进行分群，帮助企业识别高价值客户、潜在流失客户等不同群体。

## 🎯 主要功能
- **数据清洗与预处理**：自动处理缺失值、异常订单、日期转换
- **RFM指标计算**：自动计算每个客户的R、F、M值
- **客户分群**：基于自定义分箱规则对客户进行RFM分群
- **3D可视化**：使用Pyecharts生成交互式3D柱状图，展示各RFM分群在不同年份的客户数量分布
- **结果导出**：将分群结果导出为Excel文件，便于进一步分析

## 📈 RFM分群规则
项目使用以下分箱规则对客户进行分群：

| 维度 | 分箱边界 | 标签说明 |
|------|----------|----------|
| **R (最近消费)** | [-1, 79, 255, 365] | 1-3分，分数越低表示最近有消费 |
| **F (消费频率)** | [0, 2, 5, 130] | 1-3分，分数越高表示消费越频繁 |
| **M (消费金额)** | [0, 69, 1199, 206252] | 1-3分，分数越高表示消费金额越大 |

**RFM分群编码**：采用`R分数+F分数+M分数`的3位编码，如`111`表示低价值客户，`333`表示高价值客户。

## 📊 可视化说明
生成的3D柱状图包含三个维度：
- **X轴**：RFM分群编码（如111, 112, 121等）
- **Y轴**：年份（2015-2018）
- **Z轴**：该分群在对应年份的客户数量
- **颜色**：客户数量越多，颜色越接近红色
